# بنية التطبيق — المرحلة ١

الأساس بقى منفّذ ومربوط باستخدام Riverpod. الألعاب العلمية ومحرك الأسئلة الكامل لسه في المراحل الجاية.

| المسار | المسؤولية الحالية |
|---|---|
| lib/core/models.dart | بيانات الطفل والإعدادات ومحاولات التقييم وتوزيع وقت الاستخدام على الأيام |
| lib/core/storage.dart | سجل Hive محلي بإصدار ثابت؛ مفيش مسح تلقائي لو البيانات غير قابلة للقراءة |
| lib/core/providers.dart | حالة Riverpod وطابور حفظ يمنع فقدان التحديثات المتزامنة |
| lib/core/narration.dart | صوت إنجليزي محلي، إلغاء القراءة السابقة، سرعة 0.43 واختيار الصوت |
| lib/core/photo_service.dart | استيراد صورة مختارة، تصغيرها وإعادة رسمها من غير بيانات إضافية |
| lib/core/photo_cache_native.dart | تنظيف الملف المؤقت داخل كاش التطبيق فقط؛ الأصل في المعرض ما بيتلمسش |
| lib/core/design.dart وmascot.dart | الألوان والخطوط المحلية والشخصيات الأصلية والحركة |
| lib/features/onboarding/ | الاسم والجنس والشخصية أو الصورة؛ التعديل من ركن الأهل |
| lib/features/world/ | رسم الجزر والمسار ومعاينة الوحدات؛ قواعد الفتح جاهزة ومفيش تقدم وهمي |
| lib/content/catalog.dart | تحميل خريطة المنهج وإرشادات الأهل من JSON |
| lib/parent/ | بوابة الأهل والنتائج والإعدادات ومساعدة تثبيت الصوت، عربي RTL وإنجليزي |
| assets/content/catalog.json | ملف التشغيل الوحيد في المرحلة ١؛ مسودات أسئلة الكتاب غير مضمّنة |

## البيانات

- طفل واحد لكل تثبيت. تعديل الاسم أو الجنس أو الصورة ما بيعملش حساب جديد وما بيمسحش النتائج.
- schemaVersion = 1 في سجل البيانات. نسخة غير معروفة بتوقف فتح البيانات برسالة واضحة بدل مسحها.
- الصورة اختيارية: PNG بحد أقصى 512 بكسل للضلع الأطول، من غير EXIF أو اسم الملف أو عنوانه الأصلي.
- النظام بيعطينا الصورة المختارة بس؛ مفيش طلب صلاحية عامة للصور أو إذن للكاميرا.
- Hive بيحفظ الاسم الأول والجنس واختيار الشكل والصورة الاختيارية والإعدادات والنتائج والوقت على الجهاز فقط.
- النسخ الاحتياطي السحابي ونقل بيانات التطبيق بين الأجهزة متوقفين في إعدادات أندرويد.
- الطابور بيحفظ السجل قبل نشر الحالة الجديدة للواجهة. فشل الحفظ بيظهر رسالة، ومش بيتم الادعاء إن التغيير اتحفظ.
- وقت الاستخدام تقريبي، بيتحفظ كل 10 ثوانٍ أثناء فتح شاشات الطفل، وممكن آخر جزء قصير ما يتسجلش لو النظام قفل التطبيق فجأة.

## التقييم القادم

AttemptRecorder بيحتفظ بأول نتيجة لكل هدف ويستبعد اللعب الحر والتوقعات. UnitAttempt بيفصل نجوم المجهود عن نسبة الفهم؛ آخر وأفضل محاولة محفوظين في النموذج. زر معاينة وحدة ما بيكتبش محاولة ولا بيدي نجوم. الألعاب ومحرك أنواع الأسئلة وتفاصيل التقرير المنزلي هيتنفذوا في مراحلهم.

## حدود المنصات

الكود الأساسي Flutter ومش مربوط بمسارات أندرويد. الوصول للملفات المؤقتة معزول باستيراد شرطي عشان معاينة المتصفح. بناء iOS وتأهيل صلاحيات اختيار الصور عليه لسه مش ضمن النطاق الحالي. معاينة المتصفح مستقلة ببيانات متصفح محلية ومن غير قراءة صوتية؛ الصوت وواجهة اختيار الصور الأصلية لازم يتجربوا في APK على الجهاز.
