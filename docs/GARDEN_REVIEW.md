# Illustrated garden review

Current scope: the first Alive / Not Alive garden has been redesigned after parent feedback. Other Biology activities still use the earlier renderer and await the same interaction/design review. This is NOT a claim that every unit is finished.

## Play flow

- A single original picture-book garden replaces the grid and unrelated word buttons.
- A hand points to the kitten. The child can tap any of seven source-supported subjects.
- The selected subject is cropped at render time from the exact same scene, with its own matching question.
- Two picture baskets accept a tap or a drag: Alive / Not alive, with Arabic helper labels.
- First miss: hint. Second miss: the answer and a short sourced explanation. No lost lives or harsh error colors.
- Found objects remain in their natural place and gain an effort star. The complete garden can be replayed.

## Content and reporting

Scientific text remains in assets/content/playable/unit_01.json, generated by scripts/build_biology_content.py and scripts/garden_content.py from the book's pages 4–5 and answer key page 35. The illustration does not add graded science facts.

Garden practice is saved separately as unit_01.garden. The parent sees first-try, after-hint, and explanation counts. Practice does not mark the whole unit complete or fabricate quiz scores. Previous rounds are kept locally, up to 20. Existing profile and unit progress are retained.

## Art and narration

Original garden-v2.png was created using the built-in image generation tool and refined to remove brand-specific vehicle details. Prompt/provenance: GARDEN_ART_PROMPT.md. The project keeps this art locally; it is not downloaded at runtime. Raster illustration is the visual direction approved by the parent after rejecting the earlier flat code drawings.

Android keeps offline English flutter_tts. The browser preview now accepts only English voices explicitly reported as localService by the browser; it never falls back to a remote/default voice. Actual audible output still depends on installed local voices and browser support. A speaker icon shows availability; the hand, text and pictures also guide play.

## Validation and delivery

Widget tests exercise selecting the scene object, matching question/portrait, first-hint/second-explanation behavior, completing all seven objects, replay/history, and phone/tablet layouts, including 2x text. Pure tests cover score preservation and touch bounds.

The browser preview is local to 127.0.0.1:8765. No new interim APK is built; the parent requested an APK at the end. No Android device is connected, so this review does not claim physical-device verification.

Known remaining work: full-unit redesign beyond this first garden, broader curriculum, audio/celebration polish, final release signing and device checks.
