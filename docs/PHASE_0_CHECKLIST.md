# متابعة المرحلة 0

## اكتمل على الكمبيوتر

- تجهيز Flutter وDart وJava وAndroid SDK وNDK.
- إنشاء مشروع Android بمعرّف com.scienceadventure.app وأقل إصدار API 24.
- قراءة الكتاب واستخراج 9 وحدات و4 كويزات ومراجع المهارات.
- اقتراح شكل JSON مع مثال مهمة لعب وفحوص ناجحة.
- شاشة اختبار متجاوبة للموبايل والتابلت وأيقونة أصلية.
- فحص الكود والاختبارات وبناء APK وفحص توقيعه وصلاحياته ومحتوياته.
- تسجيل طلبات ولي الأمر بخصوص الاسم الشخصي، اللعب داخل مشاهد، وتقارير كل وحدة.

## المطلوب من ولي الأمر قبل إغلاق المرحلة

1. ثبّت APK حسب خطوات README.
2. افتح التطبيق.
3. اتأكد إن الكلام واضح من غير خروج برّه الشاشة.
4. اضغط Try a tap.
5. اتأكد إن الرسالة اتغيّرت إلى Your screen is ready!.
6. اضغط Try again.
7. اقفل التطبيق.
8. شغّل وضع الطيران.
9. افتح التطبيق تاني.
10. كرر تجربة اللمس.
11. قولّي نتيجة التجربة وموافقتك على بدء المرحلة 1.

مفيش جهاز Android متوصل أثناء البناء، فالتثبيت على التابلت لسه مش متحقق منه. الشاشة دي اختبار تشغيل فقط؛ إدخال الاسم والصوت وشخصية زيزو والألعاب لسه في المراحل التالية.
