# شكل ملفات المحتوى المقترح

كل وحدة وكويز ملف JSON مستقل في `assets/content/`. المرحلة 0 بتحفظ النص المستخرج، والإجابة الأصلية، ورقم السؤال، وصفحات السؤال والإجابة. ملفات المصدر عليها `status: source_draft` ومش بتتعرّض للطفل قبل تحويلها ومراجعتها.

الشكل المقترح للنسخة القابلة للعب في `schemas/question.schema.json`، ومثال حقيقي في `docs/examples/unit_01_choice_01.json`.

| الحقل | معناه |
|---|---|
| `id` | معرّف ثابت للسؤال، زي `u01.choice.01` |
| `schemaVersion` / `contentVersion` | نسخة شكل البيانات ونسخة المحتوى |
| `type` | طريقة اللعب من الأنواع السبعة المطلوبة |
| `source` | بصمة الكتاب وصفحات السؤال والإجابة ومعرّف سؤال المصدر |
| `prompt` | النص الظاهر والمنطوق، باللغة الإنجليزية |
| `options` | اختيارات بمعرّفات ثابتة ونص وصورة أصلية اختيارية |
| `answer` | قاعدة تصحيح واحدة فقط: اختيار واحد، مجموعة، توصيل، ترتيب، أو توزيع |
| `hint` | تلميح بعد أول محاولة، مرتبط بنص الكتاب |
| `explanation` | شرح الإجابة بعد المحاولة التانية، مرتبط بالكتاب |
| `safetyIds` | رسائل الأمان اللازمة قبل التفاعل |

«إجابة صحيحة واحدة» معناها قاعدة تصحيح واحدة واضحة لكل سؤال؛ مش تجاهل إن فيه أسئلة أصلًا تطلب اختيار عدة أشياء. مثال الفرز له توزيع واحد كامل، وأسئلة «أي اتنين» لها مجموعة مسموحة وعدد مطلوب. الأنشطة الحرة منفصلة عن الأسئلة المقيمة.

أنواع التفاعل: `tap-choice`, `true-false`, `drag-to-basket`, `match-lines`, `order-sequence`, `label-diagram`, `predict-then-reveal`.

ملفات أنشطة الاستكشاف هتحتوي النصوص والخطوات والأهداف ونتائج التجارب من المصدر. تجربة التوقع تسجّل التوقع أولًا، وبعدها تسمح بالكشف. المطابقة والرسم يحتاجوا بيانات أماكن الأهداف مع صور أصلية؛ التفاصيل البصرية دي هتتضاف وقت تنفيذ الوحدة.

قبل اعتماد أي وحدة، الفحص لازم يتأكد من: صحة الشكل، عدم تكرار المعرّفات، وجود كل مراجع الاختيارات، قاعدة تصحيح واحدة، تطابق الإجابة مع المصدر، عدم إظهار الإجابة قبل المحاولة، اكتمال الصوت ورسائل الأمان. صحة JSON لوحدها مش دليل على صحة علمية؛ المراجعة مع الكتاب لازمة.

## بيانات تقرير الأهل

التقدم منفصل عن المحتوى. كل محاولة تحفظ `unitId`, `contentVersion`, `questionId`, `firstAttemptCorrect`, `attemptCount`, `hintUsed`, `explanationShown`, `completedAt` ووقت اللعب الفعلي. تتخزن محليًا. توقعات التجارب تتحفظ للمقارنة من غير احتسابها أخطاء.

نسبة الإجابات الصحيحة من أول محاولة = عدد الأسئلة الصحيحة من أول مرة ÷ عدد الأسئلة المقيمة المُجابة. التقرير يعرض كمان المقام ونسبة إكمال الوحدة، عشان الإجابة على سؤال واحد ما تظهرش كإتقان للوحدة كلها. مفيش حكم رسوب أو تشخيص لقدرات الطفل.

تعديل ولي الأمر: المحرك هيقيّم قرارات داخل مشاهد لعب. prompt مهمة منطوقة، وoptions ممكن تبقى عناصر المكان القابلة للمس. مش لازم تكون واجهة سؤال واختيارات. الحقائق والإجابات مرتبطة بالكتاب، والصياغة التفاعلية أصلية.
