## الصلاحيات الفعلية داخل APK

مفيش صلاحية INTERNET أو كاميرا أو ميكروفون أو تخزين أو أي صلاحية نظام من `android.permission.*`. التطبيق مش هيطلب إذن حساس من المستخدم.

فيه إذن داخلي واحد أضافته AndroidX:

`com.scienceadventure.app.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`

نوعه `signature`، وتم التحقق من القيمة داخل APK. ده إذن داخلي لحماية استقبال رسائل النظام داخل التطبيق، ومش إذن للوصول للصور أو الملفات أو الشبكة. وجوده معناه إن قائمة الصلاحيات مش فارغة حرفيًا؛ ما ادعيناش صفر أذونات داخل الملف النهائي.

`allowBackup=false` و`supportsRtl=true` اتراجعوا داخل APK نفسه.

## ملاحظات الأدوات

- Flutter 3.47.5 stable، Dart 3.13.4، Java 21.0.12.1، Android API 36، Build Tools 36.0.0، NDK 28.2.13676358، Gradle 9.3.1.
- ملف `pubspec.lock` مثبت النسخ المستخدمة. التطبيق مفيهوش مكتبات Flutter خارجية مباشرة في المرحلة 0.
- `flutter pub outdated`: مكتبتان من تبعيات Flutter لهما نسخ أحدث، لكن Flutter الحالي مقيد بالنسخ التالية: `material_color_utilities 0.13.0` (الأحدث 0.13.1)، و`test_api 0.7.12` (الأحدث 0.7.14). مفيش تحديث متوافق متاح لهم في الحل الحالي؛ ما عملناش تجاوز للقيود.
- أثناء البناء ظهر تحذير إن قارئ بيانات SDK بيفهم XML لحد الإصدار 3 بينما بعض بيانات الأدوات إصدارها 4. البناء اكتمل والفحوص نجحت. ده تحذير أدوات، مش خطأ في محتوى اللعبة.
- فحص أدوات Android ناجح. Android Studio مش مثبت؛ البناء اشتغل بأدوات Android الرسمية مباشرة. أدوات الويب وWindows مش مطلوبة للهدف الحالي.
- تقليل الحجم والإخفاء والتوقيع الدائم للنسخة النهائية في المرحلة 7. إعداد R8 موجود للإصدار، لكنه لم يُختبر ببناء Release. بناء Release متوقف عمدًا لحد وجود ملف التوقيع الخاص.
